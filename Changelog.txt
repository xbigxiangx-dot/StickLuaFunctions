# StickLuaFunctions Changelog

v0.9.0
------
## 新增
- Listener `ST_AddAttackIndexListener`：hook 物理攻击序号，输入参数为 `sourceSprite, targetSprite, attackIndex`。
- opcode#1：`special = 1` 时增加副手攻击次数，`special = 0` 时增加该武器的攻击次数；仅对 `increment` 模式有效。


v0.8.2
------
## 工程与兼容性
- WeiDU 安装程序新增简体中文和英文双语选择。


v0.8.1
------
## 新增
- Listener `ST_AddHideInPlainSightListener`：hook 随地潜行判定，输入参数为 `sprite`；监听器返回 `true` 时允许角色随地潜行。
- 函数 `ST_GetAllKitIds(sprite, includeGeneralist)`：以表格形式返回角色的原始及额外 kit ID；默认排除通用法师，`includeGeneralist == true` 时将其包含在内。
- Listener `ST_AddSaveModListener`：hook 豁免修正值计算，输入参数为 `sprite, effect`。

## 变更
- Hook `ST_RegisterHook_HideInPlainSight`：优化随地潜行判定 hook 的实现，并支持识别由 StickMultiKit 添加为额外宗派的影舞者。


v0.8.0
------
## 新增
- 函数 'ST_MatchIds(sprite, idsIndex, idsValue)'：按 IDS 类型匹配目标，支持 'ALIGN.IDS' 的 mask 判断，支持对额外 kidId 的判断。
- 函数 'ST_MatchKitId(sprite, kitId)'：检测角色是否具有任何(包括额外的)符合输入的kitId。
- 函数 'ST_SetExKitId(sprite, exKitIndex, kitId)'：将额外 kit ID 写入指定序号的角色本地变量，变量名格式为 'ST_ExKit#_High' 及 'ST_ExKit#_Low' (此处'#'等于exKitIndex)。
- 函数 'ST_GetExKitId(sprite, exKitIndex)'：从角色本地变量读取指定序号的额外 kit ID。

##工程与兼容性：
- 2DA变量现在以 _2DA 作为后缀


v0.7.0
------
## 新增
- 函数 'ST_GetSprite(spriteOrId)'：将 'spriteId' 或 'sprite' 统一解析为 'sprite'，用于支持部分 hook 函数同时接受两类输入。
- 函数 'ST_GetResRef(m_resRef)'：读取 resref 字符串。
- 函数 'ST_ApplyWeaponHitEffects(sourceSprite, targetSprite, weaponRes, abilityIndex)'：应用武器 ability 携带的命中特效。
- 函数 'ST_ApplyCriticalEffects(sourceSprite, targetSprite, hitOrMiss, weaponType)'：应用致命一击/致命失误条目中的 EFF 效果。
- Listener 'ST_AddAttackDamModListener'：hook 物理攻击伤害修正值，输入参数为 'sourceSprite, targetSprite, damModified'，返回值可覆盖 'damModified'。
- Listener 'ST_AddMeleeAttackListener'：hook 物理攻击命中后的场景，输入参数为 'sourceSprite, targetSprite, bBlocked'。
- Listener 'ST_AddSaveDCModListener'：hook 法术/物品能力的豁免 DC 计算场景，输入参数为 'sprite, effect'。
- 函数 'ST_RunMeleeAttackListeners(sourceSprite, targetSprite, bBlocked)'：统一执行通过 'ST_AddMeleeAttackListener' 注册的监听器，供真实攻击 hook 和模拟攻击等场景复用。

## 变更
- Listener 'ST_AddHitRollListener'：新增重骰处理机制。监听器返回正数时进行取高重骰，返回负数时进行取低重骰。
- 全局状态 'st_currentAttack'：保存当前攻击者、目标、最终命中骰值（0-19）以及 'sourceTag'。
- Listener 'ST_HitRollModListener' 更名为 'ST_HitModListener'，以更准确描述其功能。
- 函数 'ST_GetCurrentWeapon(sprite, getCurrentAttack)'：当 'getCurrentAttack == true' 时，第二返回值改为 'fightingStyle'，第三返回值为 'isLeftAttack'。
- 函数 'ST_GetCurrentWeapon(sprite, getCurrentAttack)'：当 'getCurrentAttack == false' 时，新增第四返回值 'isLeftAttack'。
- 函数 'ST_FindEffectsAll(sprite, filter, firstOnly)'：当 'firstOnly == true' 时，按装备效果、限时效果、持久效果的顺序查找，找到后停止继续查找。
- 函数 'ST_MockAttack'：扩展为可模拟近战/远程物理攻击；新增对命中骰、命中修正、伤害修正 hook 的调用；拆分致命一击与致命失误；新增 IDS 命中/伤害修正处理；模拟攻击完成后重置 'st_currentAttack.sourceTag'。
- Listener 'ST_AddBackstabListeners' 更名为 'ST_AddBackstabListener'；背刺 hook 新增成功分支，监听器输入参数改为 'sourceSprite, targetSprite, isBackstabSuccessful'。失败分支中监听器返回 'true' 时，可强制进入背刺成功流程。
